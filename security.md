# Security Statement

## Intended Users

This repo contains my coursework (Python scripts, Jupyter notebooks, and small datasets). It is intended for me as the author, and for the instructor and TAs who review it.

## Risk Assessment

The repo has no production systems, passwords, or real user data. If it fell into the wrong hands, the main concerns would be someone copying my assignment solutions or chanigng my code.

## Steps Taken

- A `.gitignore` file keeps local files (virtual environments, cache files) out of the repo.
- A `CODEOWNERS` file makes me the owner of the code.
- I do not commit passwords, keys, or other secrets.
- Two-factor authentication is enabled on my GitHub account.
